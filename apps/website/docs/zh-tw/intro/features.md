# 功能

## 開啟課程

如果目前開啟的工作區中沒有課程，可以點 **「開啟課程」** 按鈕，或在命令選擇區搜尋並使用 **LearnByDiff: 開啟課程**。

<img src="../../images/features-open-course.png" alt="開啟課程" style="height: 400px; width: auto; margin: 0 auto; display: block;"/>

在清單中點選一門官方課程即可開啟。也可以在輸入框中填入 course.jsonc 路徑或 URL 並確認。

## 章節切換與檢視

開啟課程後，Explorer 會出現 **Learn By Diff** 欄位，列出目前工作區對應的課程章節。

<img src="../../images/features-chapter-switch-and-view.png" alt="章節切換與檢視" style="height: 400px; width: auto; margin: 0 auto; display: block;"/>

在 Learn By Diff 檢視中，你可以點按鈕進行以下操作：

| 操作                    | 作用                                           |
| ----------------------- | ---------------------------------------------- |
| **捲動到目前章節**      | 定位目前章節                                   |
| **搜尋章節**            | 依標題或 ID 查找並定位章節，支援模糊搜尋       |
| **開啟章節文件**        | 開啟該章節的課程文件                           |
| **未開始** / **已完成** | 將工作區程式碼切換為該章節的未開始或已完成快照 |

注意，當你切換快照時，會提示**是否覆蓋目前資料夾中的程式碼**，以防止誤操作。

## 檔案比較

<img src="../../images/features-file-compare.png" alt="檔案比較" style="height: 400px; width: auto; margin: 0 auto; display: block;"/>

在 Learn By Diff 欄位中可以展開章節，查看該章的變更清單。點檔案名稱即可查看與原始檔控制相同類型的比較。

## 章節比較

若要將不同章節、不同完成狀態的程式碼放在一起執行比較，可以點章節上的 **「...」** 按鈕，再選擇 **「開啟未開始資料夾」** 或 **「開啟已完成資料夾」**。對應程式碼會下載到本機，並以獨立資料夾加入工作區。
