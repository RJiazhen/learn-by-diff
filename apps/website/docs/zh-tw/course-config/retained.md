# 保留檔案

切換章節時，學習目錄裡的原始碼會被對應的章節快照**取代**，而不是把兩章的檔案混在一起。

在沒有任何設定的情況下，除了 `.git` 和 `.learn` 目錄，**其他所有檔案和資料夾都會被刪除**，再進行覆蓋。

因此，為了避免開發所需的檔案（例如 `node_modules/` 這類依賴目錄）被刪除，可以設定 `.gitignore`，將這些檔案和資料夾加入忽略清單。

## 注意

- 只保留**頂層**被忽略的路徑。例如忽略了 `node_modules/`，根目錄的 `node_modules/` 會留下；如果忽略的是 `src/generated/`，切章時整個 `src` 仍會被快照取代。
- 未被 `.gitignore` 忽略的原始碼檔案，切章時仍會依快照覆蓋。
