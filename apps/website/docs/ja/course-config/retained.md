# 残すファイル

章を切り替えると、学習フォルダー内のソースは、その章のスナップショットで**置き換え**られます。2 章のファイルが混ざることはありません。

追加の設定がない場合、`.git` と `.learn` 以外の**すべてのファイルとフォルダーは削除**され、その後スナップショットが書き込まれます。

開発に必要なもの（例: `node_modules/`）を残すには、`.gitignore` に書いてください。無視されたファイルやフォルダーは削除されません。

## 注意

- 残るのは**トップレベル**で無視されているパスだけです。`node_modules/` を無視するとルートの `node_modules/` は残ります。`src/generated/` を無視しても、章を切り替えると `src` 全体がスナップショットで置き換わります。
- `.gitignore` で無視されていないソースファイルは、スナップショットで上書きされます。
